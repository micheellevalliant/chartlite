ChartLite - installer
Hosted at: https://micheellevalliant.github.io/chartlite/src/taskpane.html

1. Double-click install.bat
2. Close and reopen PowerPoint
3. Home tab > ChartLite

No Node.js or server needed. Updates published to https://micheellevalliant.github.io/chartlite/src reach you automatically.
To remove: uninstall.bat
